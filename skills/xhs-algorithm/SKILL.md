# 小红书推荐算法知识库

## 定位

这是一个**知识参考 skill**，不产出文件，不修改数据。它的作用是：

1. 用户问算法相关问题时，给出系统性解答
2. 其他 skill 在做判断时（打分、预测、复盘归因），参考平台机制理解"为什么这条数据好/差"
3. 帮用户理解 rubric 各维度跟算法的对应关系

## 核心评分模型：CES

CES（Community Engagement Score，社区互动分）是小红书衡量笔记质量的核心模型：

```
CES = 点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×8
```

**权重解读**：

- **关注（×8）**：最高权重。陌生人看完直接关注 = 最高认可度。这解释了为什么"人设感强"的内容长期涨粉能力强
- **评论+转发（×4）**：深度互动。评论代表"我有话想说"（情感共鸣或争议），转发代表"我想让别人看到"（社交货币）
- **点赞+收藏（×1）**：基数大但权重低。收藏更有价值——代表"我以后还要用"（工具价值/长期参考）

**与 rubric 的对应关系**：

| CES 因子 | 对应 rubric 维度 | 逻辑 |
|----------|-----------------|------|
| 评论 | ER（情感共鸣）| 共鸣强 → 用户想评论表达 |
| 转发 | QL（金句密度）+ AB（受众广度）| 有金句 + 受众广 → 值得分享 |
| 收藏 | 工具价值（rubric 暂未单独建维度）| 攻略/教程/干货 → 收藏 |
| 关注 | 综合人设力（跨多维度）| 单篇无法驱动，需内容矩阵 |

### 隐藏因子

CES 之外，算法还考虑：

- **完播率/阅读完成率**：视频是否看完、图文是否滑到最后一张。对应 rubric 的 NA（叙事性）——有悬念和节奏才看得完
- **内容原创度**：与已有内容高度相似会被降权。纯搬运/洗稿/AI 模板化内容都会命中
- **负向信号**：举报、"不感兴趣"大幅拉低评分。争议性内容是双刃剑
- **互动时效**：发布后前 30 分钟的互动权重约 1.5 倍（详见下方时效表）

## 流量池四级分层

每篇笔记从最小流量池开始，逐级突破：

### 第一级：初始池（200-500 曝光）

- **推送对象**：粉丝 + 少量兴趣标签匹配用户
- **观察周期**：2-6 小时
- **突破条件**：CTR ≥ 15%、互动率 ≥ 5%、无负向信号
- **对创作者的含义**：封面+标题决定生死（CTR），这就是 rubric 里 HP（Hook Potential）维度存在的原因

### 第二级：扩展池（1000-5000 曝光）

- **推送对象**：更广泛的兴趣标签用户
- **观察周期**：6-24 小时
- **突破条件**：CES 在同池排名前 20%，评论区有真实讨论
- **对创作者的含义**：光有点击不够，要有深度互动（评论质量）

### 第三级：热门池（1万-10万 曝光）

- **推送对象**：突破兴趣标签限制，向泛人群推送（发现页热门）
- **观察周期**：24-72 小时
- **对创作者的含义**：能到这一级的内容必须有 AB（受众广度）——太垂直的话泛人群不买单

### 第四级：爆款池（10万+ 曝光）

- **推送对象**：平台级热门、可能进热搜/编辑精选
- **生命周期**：数周甚至数月
- **对创作者的含义**：需要 SR（社会共鸣）或极强的 ER — 触及集体情绪才能破圈

### 时间窗口

| 时间段 | 角色 | 意味着 |
|--------|------|--------|
| 前 1 小时 | 黄金观察期 | 互动权重 1.5x，决定是否进第二级 |
| 前 4 小时 | 核心推荐期 | 互动权重 1.0x |
| 前 24 小时 | 突破攀升期 | 权重 0.7x，最后机会 |
| 24 小时后 | 长尾期 | 权重 0.3x，主要靠搜索流量续命 |

**关键认知**：超过 24 小时未突破，推荐流量大概率停滞——但搜索关键词布局合理的笔记，仍可能通过搜索获得"二次爆发"。

## 五大推荐影响因素

### 1. 账号权重

- 实名认证 / 专业号 → 基础权重加成
- 内容垂直度（持续产出同一领域）→ 标签精准度提高
- 历史表现（过去 30 天笔记平均表现）→ 冷启动流量池大小
- 违规记录 → 恢复周期 30-90 天
- 活跃度（发布频率、互动频率）

**对你的含义**：新号前 5 条对账号权重影响很大。这就是 rubric 里"前5条是数据采集期"的平台依据——这 5 条笔记在帮算法给你的账号打标签。

### 2. 标签匹配（三层标签体系）

- **一级标签**：美妆、穿搭、美食、科技、职场等大类
- **二级标签**：底妆、眼妆；家常菜、烘焙；AI工具、编程等细分
- **三级标签**：长尾（"黄皮适合的口红色号""文科生学编程"）

标签越精准 → 初始推荐匹配度越高 → CTR 越高 → 突破第一级概率越大。

**对你的含义**：白日梦想猪号的标签是"文科转码 + AI + 独立开发"，煮理人号的标签是"做饭 + 菜谱 + 厨房工具"。两个号混发会让算法困惑你的标签归属。

### 3. 发布时间

| 时间段 | 流量级别 | 适合内容类型 |
|--------|----------|-------------|
| 工作日 12:00-14:00 | 高（午休刷手机）| 轻松短内容 |
| 工作日 18:00-22:00 | 最高（下班后）| 深度内容、长视频 |
| 周六日 10:00 开始 | 高（全天）| 攻略、教程类 |
| 工作日 7:00-9:00 | 中（通勤）| 短平快 |

### 4. 内容类型偏好（2025）

- 平台持续加大**视频推荐权重**（尤其 60 秒以内短视频）
- 图文仍是基本盘但需更高质量（精修图 > 随手拍）
- 合集/攻略类在搜索场景表现更好（长尾流量）
- 轮播图文（多图教程）互动率高于单图

### 5. 互动时效权重

| 发布后时间 | 互动权重倍数 |
|-----------|-------------|
| 0-30 分钟 | ×1.5 |
| 30 分钟-4 小时 | ×1.0 |
| 4-24 小时 | ×0.7 |
| 24 小时以上 | ×0.3 |

**操作含义**：发布后 30 分钟内的互动最值钱。可以发布后主动在评论区引导讨论、回复前几条评论。

## 2025-2026 算法趋势

### 搜索+推荐双驱动

小红书正从"推荐为主"转向"搜推双驱"：搜索流量占比从早期 20% 提升至约 35%-40%。SEO 优化变得极其重要：标题含关键词、正文自然嵌入搜索词、标签精准覆盖。

### AI 内容检测加严

平台引入 AI 内容检测，对低质量、搬运、AI 生成内容更严格限流。原创性和真实体验成为核心要素。纯 AI 写的文案如果没有个人经历/真实场景，会被降权。

### 社交关系链权重增加

好友间的私信、评论、点赞正在成为推荐的重要信号。"你朋友赞过的笔记"出现在推荐流中的概率增大。

### LBS 本地推荐

基于地理位置的本地内容推荐权重增加。标注了地点的笔记在当地用户中获得额外曝光。

## 长尾流量特征（小红书 vs 抖音的关键区别）

小红书的长尾效应远强于抖音：高质量攻略类笔记可持续获得流量 6-12 个月。

**长尾流量来源**：搜索流量、相关推荐、收藏回流（用户收藏后过段时间打开）。

**搜索用户 vs 推荐用户的价值差异**：

| 指标 | 搜索用户 | 推荐用户 |
|------|---------|---------|
| 互动率 | 高 50%-80% | 基准 |
| 收藏率 | 2-3 倍 | 基准 |
| 商品点击率 | 3-5 倍 | 基准 |

**对创作者的含义**：如果你的内容有"长期搜索价值"（教程、攻略、工具推荐），即使推荐流量一般，搜索流量也能持续贡献。这解释了为什么"收藏率高但点赞一般"的笔记长期表现往往优于"点赞高但收藏低"的。

## 与 rubric 打分的对照表

| rubric 维度 | 驱动的算法行为 | 对应 CES 因子 |
|------------|--------------|--------------|
| HP（Hook Potential）| 提高 CTR → 突破第一级 | 间接（CTR 是前置条件）|
| ER（Emotional Resonance）| 驱动评论 | 评论×4 |
| QL（Quotable Lines）| 驱动转发/截图 | 转发×4 |
| NA（Narrativity）| 提高完播率/阅读完成率 | 隐藏因子 |
| AB（Audience Breadth）| 突破第二→三级（泛人群）| 间接 |
| SR（Social Resonance）| 突破第三→四级（破圈）| 间接 |
| SAT（Satire Depth）| 制造争议→评论 or 负向信号 | 评论×4 or 负向 |

**SAT 是双刃剑**：讽刺/反讽如果拿捏到位 → 大量讨论；过火 → 举报。rubric 对 SAT 的打分要考虑"风险回报比"。

## 对你操作层面的几个核心推论

1. **前 5 条笔记决定账号标签** → 不要乱发，每条都按 rubric 认真打磨
2. **评论权重是点赞的 4 倍** → ER（情感共鸣）维度在 CES 层面比你以为的更重要
3. **搜索流量占比 35-40%** → 标题和正文要自然包含目标关键词，长期价值内容优先
4. **前 30 分钟互动 1.5 倍** → 发布后立刻在评论区留一条引导互动的评论
5. **长尾 > 短爆** → 教程/攻略类收藏率高的内容，6 个月后仍在贡献流量
6. **AI 检测加严** → 如果用 AI 辅助写稿，必须融入个人真实经历，纯模板化会被降权

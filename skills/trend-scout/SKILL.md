# trend-scout — 热点选题探测

## 这个 Skill 做什么

从多个热点源（小红书热门、微博热搜、知乎热榜、AI/科技热点等）抓取当天的热门话题，然后：
1. 过滤掉跟你完全无关的（比如娱乐八卦、体育赛事）
2. 对剩下的用 rubric 粗打分
3. 推荐"热点 × 你的人设"的交叉选题角度

## 为什么需要它

你不是追热点的营销号，但好内容往往是"个人经历 × 时代热点"的交叉——比如"奥德赛时期"就是一个你可以蹭的热梗。问题是你不可能每天刷完所有平台的热搜。trend-scout 帮你做这个筛选工作，每天花 30 秒看一眼"今天有没有跟我相关的热点"。

## 工作目录

从 `~/.social-media-sniffer/config.json` 读取 active workspace：`config.workspaces[config.active]`

候选池文件：`<workspace>/topics/candidates.md`

## 热点源

| 来源 | 方式 | 适合谁 |
|---|---|---|
| 用户手动粘贴 | 用户把看到的热点 URL/标题粘过来 | 所有人（兜底方案） |
| 小红书发现页 | 从浏览器插件导出的 explore JSON | 做小红书的人 |
| 微博热搜 | 公开 API / 网页爬取 | 蹭大众话题 |
| 知乎热榜 | 公开 API | 深度话题 |
| AI/科技热点 | HN / Product Hunt / AI 新闻聚合 | 技术方向创作者 |
| 即刻/Twitter | 用户粘贴 | 小众圈层热点 |

**默认只用"用户手动粘贴"**——其他源按需开启，不强制配置。

## 工作流程

### Phase 1: 收集热点

按用户指定的来源抓取。如果没指定，走"手动粘贴"模式：

```
你想从哪里找灵感？
- 直接粘贴你看到的热门话题/链接（每行一条）
- 或者把浏览器插件导出的 explore JSON 文件路径给我
```

### Phase 2: 与你的方向交叉

读取用户的 creator-profile 画像，判断每条热点是否跟你的方向有交集：

| 你的标签 | 热点 | 交叉？ |
|---|---|---|
| 文科转码、独立开发、AI | "奥德赛时期"热梗 | ✅ 迷茫×转码×个人经历 |
| 文科转码、独立开发、AI | 某明星离婚 | ❌ 无关 |
| 文科转码、独立开发、AI | "AI 会取代程序员吗" | ✅ AI×职业焦虑 |

过滤掉无交集的。

### Phase 3: 粗打分

对每条有交集的热点，假设"如果我来做这个话题"，用 rubric 粗估 7 维度：
- 这个话题能给我多少 ER/SR/AB？
- 我能在这个话题上做出 HP=4+ 的标题吗？
- 这个话题我有没有独特视角（vs 所有人都在说同样的话）？

### Phase 4: 推荐

按 composite 排序，输出 top 3-5：

```
🔥 今日热点 × 你的方向

1. 「草台班子」二次翻红（微博热搜）
   粗估 composite: 7.8
   交叉角度：你转码经历中"如果世界是个草台班子呢"的 moment → 个人故事版
   SR=5（正在热）HP=4（反直觉叙事）ER=4（自我认同）
   
2. 「AI 焦虑正在杀死应届生」（知乎热榜）
   粗估 composite: 7.2
   交叉角度：你作为文科转码成功 + 大厂在职 → 有资格给 counter-narrative
   SR=4 HP=3 ER=3 AB=5
   
3. ...

要加入候选池吗？回 "1, 2" 或 "all" 或 "none"
```

### Phase 5: 落盘

用户选择后，写入 `<workspace>/topics/candidates.md`。
已拒绝的记录在本地缓存，6 个月内不再推。

## 关键规则

1. **交叉优先**——不是给你看所有热点，只给你看"跟你有关的"
2. **粗打分要诚实**——标注"基于话题粗估，非成稿打分"
3. **不替代选题思考**——trend-scout 给素材，social-media-topic-creator 做深度规划
4. **时效性标注**——标注热点是"上升期/峰值/尾声"，过了峰值的要谨慎
5. **去重**——已经做过的话题不再推

## 与其他 skill 的关系

- **上游**：用户日常触发，或 topic-creator 发现"候选池空了"时引导来这里
- **下游**：选中的话题进入 candidates → topic-creator 做详细规划 → draft-score 打分
- **参考**：creator-profile 提供"你的方向"用于交叉过滤；rubric 提供打分标准
- **联动**：如果某个热点你做了且数据好（post-retro 验证），说明这类热点适合你 → 影响 rubric-evolve
